## Overview

**SFCTL** (SmartFlasher Control Protocol) is a custom NMEA-based control protocol used in the SmartFlasher application for device configuration and management. It follows the standard NMEA sentence format with proper checksums, similar to FLARM (PFLAA, PFLAU) and GPS (GPGGA, GPRMC) protocols.

### Key Features

- **NMEA-compliant**: Uses standard NMEA format with checksums
- **Type-safe**: Structured parsing with validation
- **Callback-based**: Register handlers for SFCTL messages
- **Not bridged**: SFCTL messages are NOT forwarded to bridge devices
- **Statistics tracking**: Counts all SFCTL messages received
- **Extensible**: Generic command support for custom operations

### Purpose

SFCTL provides a standardized way to:
1. **Manage device parameters** - Read, write, list, and reset configuration
2. **Control device behavior** - Send commands to control device operations
3. **Monitor system status** - Retrieve uptime, memory, frame statistics
4. **Handle errors** - Acknowledge operations and report errors with codes

### Ports

SFCTL commands are accepted on four ports:

| Port | Connection | Accepted sentences |
|---|---|---|
| FLARM (UART2, RJ45 **FLARM**) | RS-232, *Flarm Port Baudrate* (default 19200) | All (FLARM data and SFCTL). Primary port. |
| DISPLAY (UART1, RJ45 **DISPLAY**) | RS-232, *Display Port Baudrate* (default 19200) | **SFCTL** handled locally. Everything else is forwarded unchanged to the FLARM port (two-way bridge) while *Display Bridge* (`BRIDGE_ENABLED`) and *Two-way Bridge* (`BRIDGE_TWO_WAY`) are on, otherwise dropped. |
| Bluetooth (SPP) | Bluetooth Classic, device name = *Device name* | Same as DISPLAY: **SFCTL** handled locally, everything else forwarded to the FLARM while the Bluetooth bridge is active, a client is connected and *Two-way Bridge* (`BRIDGE_TWO_WAY`) is on. |
| Debug (UART0, **USB-C**) | USB serial, monitor speed | All (FLARM data and SFCTL). Service and development. |

Each port has its own NMEA parser, so data on one port never corrupts a sentence on the other. SFCTL replies (`ACK`, `NACK`, `STATUS`…) are sent back **to the port the command came from**. Other frames generated by a command, e.g. `$PFLAI,PILOTEVENT` from `EVENT`, always go to the FLARM port.

On the DISPLAY and Bluetooth ports, bytes are forwarded to the FLARM as soon as they cannot be the start of a `$SFCTL` sentence (at most 6 bytes are held back), so FLARM configuration and other non-NMEA traffic pass through unchanged. `$SFCTL` lines longer than 128 bytes are dropped and never forwarded. Implementation: `lib/SFProto/src/UplinkFilter.*`; host unit test: `test/uplink_filter_test.cpp`.

// SFCTL Message types enum
enum SFCTLType {
    SFCTL_ACK = 1,        // Acknowledgment
    SFCTL_NACK = 2,       // Negative acknowledgment (error)
    SFCTL_LIST = 3,       // List all parameters
    SFCTL_DEFAULTS = 4,   // Reset to defaults
    SFCTL_READ = 5,       // Read parameter (command "R")
    SFCTL_WRITE = 6,      // Write parameter (command "W")
    SFCTL_STATUS = 7,     // Status message
    SFCTL_STATS = 8,      // Statistics
    SFCTL_FLASH = 9,      // Flash control
    SFCTL_RESET = 10,     // System reset/restart
    SFCTL_UNKNOWN = 0     // Unknown command
};

// SFCTL structure
struct SFCTL {
    SFCTLType type;      // Message type
    String command;      // Command or parameter name
    String value;        // Parameter value or status message
    String errorCode;    // Error code (for NACK)
    
    SFCTL() : type(SFCTL_UNKNOWN), command(""), value(""), errorCode("") {}
    bool parse(const std::vector<String> &fields);
};

## Message Types

### 1. SFCTL_ACK (Acknowledgment)
Confirms successful operations and returns parameter values.

**Examples:**
```
$SFCTL,ACK,DEVICE_NAME,SmartFlasher*75
$SFCTL,ACK,POWER_LEVEL,35*7B
$SFCTL,ACK,LIST*05
$SFCTL,ACK,DEFAULTS*1F
```

### 2. SFCTL_NACK (Negative Acknowledgment)
Reports errors with specific error codes.

**Examples:**
```
$SFCTL,NACK,UNKNOWN*01
$SFCTL,NACK,READ_ONLY*10
$SFCTL,NACK,INVALID_VALUE*0C
$SFCTL,NACK,TIMEOUT*12
```

### 3. SFCTL_LIST (List Parameters)
Requests all available parameters.

**Example:**
```
$SFCTL,LIST*60
```

### 4. SFCTL_DEFAULTS (Reset to Defaults)
Resets all parameters to factory defaults.

**Example:**
```
$SFCTL,DEFAULTS*7A
```

### 5. SFCTL_READ (Read Parameter)
Reads a specific parameter value using command "R".

**Examples:**
```
$SFCTL,R,DEVICE_NAME*5C
$SFCTL,R,POWER_LEVEL*4A
```

### 6. SFCTL_WRITE (Write Parameter)
Writes a new value to a parameter using command "W".

**Examples:**
```
$SFCTL,W,DEVICE_NAME,NewName*0E
$SFCTL,W,POWER_LEVEL,40*67
$SFCTL,W,BT_ENABLED,true*2F
```

### 7. SFCTL_STATUS (Status Message)
Sends system status information.

**Request:**
```
$SFCTL,STATUS*76
```

### 8. SFCTL_STATS (Statistics)
Requests or reports frame statistics.

**Request:**
```
$SFCTL,STATS*23
```

**Responses:**
```
$SFCTL,STATS,TOTAL,1234*65
$SFCTL,STATS,FPS,10.5*7C
$SFCTL,STATS,PFLAA,456*4E
```

### 9. SFCTL_FLASH (Flash Control)
Controls LED flash operations.

**Examples:**
```
$SFCTL,FLASH,ON*1F
$SFCTL,FLASH,OFF*51
$SFCTL,FLASH,MODE,2*03
```

### 10. SFCTL_RESET (System Reset)
Performs a complete system restart (ESP32 reboot).

**Request:**
```
$SFCTL,RESET*37
```

**Response:**
```
$SFCTL,ACK,RESET,RESTARTING*69
```

**Note:** The device will restart immediately after sending the acknowledgment. A small delay (100ms) is used to ensure the ACK message is transmitted before the restart occurs.

## NMEA Format

### Standard NMEA Sentence Structure

```
$SFCTL,<command>,<param1>,<param2>,...*<checksum>
```

- **$** - Start delimiter
- **SFCTL** - Sentence identifier
- **,** - Field separator
- **\*** - Checksum delimiter
- **<checksum>** - Two-digit hexadecimal XOR checksum

### Checksum Calculation

The checksum is calculated by XORing all characters between `$` and `*` (exclusive).

**Example:**
```
$SFCTL,ACK,TEST*XX
Checksum = 'S' ^ 'F' ^ 'C' ^ 'T' ^ 'L' ^ ',' ^ 'A' ^ 'C' ^ 'K' ^ ',' ^ 'T' ^ 'E' ^ 'S' ^ 'T'
```

### Parsing Implementation

From `NMEAStructures.cpp:345-411`:

```cpp
bool SFCTL::parse(const std::vector<String> &fields)
{
    if (fields.size() < 1)
        return false;

    command = fields[0];

    // Determine message type based on command
    if (command == "ACK")
    {
        type = SFCTL_ACK;
        if (fields.size() > 1)
            value = fields[1];
        if (fields.size() > 2)
            value += "," + fields[2];
    }
    else if (command == "NACK")
    {
        type = SFCTL_NACK;
        if (fields.size() > 1)
            errorCode = fields[1];
    }
    else if (command == "LIST")
    {
        type = SFCTL_LIST;
    }
    else if (command == "DEFAULTS")
    {
        type = SFCTL_DEFAULTS;
    }
    else if (command == "STATUS")
    {
        type = SFCTL_STATUS;
    }
    else if (command == "STATS")
    {
        type = SFCTL_STATS;
    }
    else if (command == "R")
    {
        type = SFCTL_READ;
        if (fields.size() > 1)
            value = fields[1];
    }
    else if (command == "W")
    {
        type = SFCTL_WRITE;
        if (fields.size() > 1)
            value = fields[1];
        if (fields.size() > 2)      
            value += "," + fields[2];
    }
    else
    {
        type = SFCTL_UNKNOWN;
    }

    return true;
}
```

## Usage Examples

### Example 1: Basic Setup and Registration

```cpp
#include <Arduino.h>
#include "SFProtocol.h"

HardwareSerial SerialPort(1);
SFProtocol proto(&SerialPort);

void setup() {
    Serial.begin(115200);
    SerialPort.begin(115200, SERIAL_8N1, 16, 17);
    
    // Add parameters
    proto.addString("DEVICE_NAME", "SmartFlasher", true);
    proto.addInt("POWER_LEVEL", 35, true);
    proto.addFloat("VOLTAGE", 3.7, true);
    
    proto.begin();
    
    // Register SFCTL handler
    proto.registerSFCTLRoute([&](const SFCTL &msg) {
        if (msg.type == SFCTL_LIST) {
            // List all parameters
            for (auto &p : proto.getParams()) {
                proto.sendNMEA(proto.getNMEAGenerator().generateSFCTL(
                    p.name, {p.toString()}
                ));
            }
            proto.ack("LIST");
        }
    });
}

void loop() {
    proto.process();
}
```

```cpp
proto.registerSFCTLRoute([&](const SFCTL &msg) {
    // Handle unknown commands
    if (msg.type == SFCTL_UNKNOWN) {
        log_i("Unknown SFCTL command: %s", msg.command.c_str());
        proto.nack("UNKNOWN");
        return;
    }

    // Handle STATUS command
    if (msg.type == SFCTL_STATUS) {
        log_i("STATUS command received");
        NMEAGenerator &gen = proto.getNMEAGenerator();

        // Send system status including frame statistics
        proto.sendNMEA(gen.generateSFCTL_STATUS("UPTIME," + String(millis() / 1000)));
        proto.sendNMEA(gen.generateSFCTL_STATUS("FRAMES_COUNT," + String(proto.getFrameCount())));
        proto.sendNMEA(gen.generateSFCTL_STATUS("FRAMES_PER_SEC," + String(proto.getFramesPerSecond(), 2)));
        proto.sendNMEA(gen.generateSFCTL_STATUS("HEAP," + String(ESP.getFreeHeap())));
        proto.sendNMEA(gen.generateSFCTL_STATUS("WIFI_CLIENTS," + String(WiFi.softAPgetStationNum())));
        proto.sendNMEA(gen.generateSFCTL_STATUS("FLASH_MODE," + String(ledFlasher.getMode())));
        proto.sendNMEA(gen.generateSFCTL_ACK("STATUS", "COMPLETE"));
        return;
    }

    // Handle STATS command
    if (msg.type == SFCTL_STATS) {
        log_i("STATS command received");
        NMEAGenerator &gen = proto.getNMEAGenerator();

        // Send comprehensive frame statistics
        proto.sendNMEA(gen.generateSFCTL("STATS", {"TOTAL", String(proto.getFrameCount())}));
        proto.sendNMEA(gen.generateSFCTL("STATS", {"FPS", String(proto.getFramesPerSecond(), 2)}));
        proto.sendNMEA(gen.generateSFCTL("STATS", {"PFLAA", String(proto.getPFLAACount())}));
        proto.sendNMEA(gen.generateSFCTL("STATS", {"PFLAU", String(proto.getPFLAUCount())}));
        proto.sendNMEA(gen.generateSFCTL("STATS", {"GPGGA", String(proto.getGPGGACount())}));
        proto.sendNMEA(gen.generateSFCTL("STATS", {"SFCTL", String(proto.getSFCTLCount())}));
        proto.sendNMEA(gen.generateSFCTL("STATS", {"INVALID", String(proto.getInvalidCount())}));
        proto.sendNMEA(gen.generateSFCTL_ACK("STATS", "COMPLETE"));
        return;
    }

    // Handle LIST command
    if (msg.type == SFCTL_LIST) {
        log_i("LIST command received");
        for (auto &p : paramManager.getParams()) {
            proto.sendNMEA(proto.getNMEAGenerator().generateSFCTL(
                p.name, {p.toString()}
            ));
        }
        proto.ack("LIST");
        return;
    }

    // Handle DEFAULTS command
    if (msg.type == SFCTL_DEFAULTS) {
        paramManager.restore();
        proto.ack("DEFAULTS");
        return;
    }

    // Handle WRITE command
    if (msg.type == SFCTL_WRITE) {
        std::vector<String> fields = proto.split(msg.value);
        String paramName = fields[0];
        String paramValue = fields.size() > 1 ? fields[1] : "";

        log_i("WRITE: %s = %s", paramName.c_str(), paramValue.c_str());

        // Find and validate parameter
        Parameter *p = paramManager.findParam(paramName);
        if (!p) {
            proto.nack("UNKNOWN");
            return;
        }
        if (!p->writable) {
            proto.nack("READ_ONLY");
            return;
        }

        // Write the value
        p->setValueFromString(paramValue);
        paramManager.saveParam(*p);
        proto.ack(p->name + "," + p->toString());
        return;
    }

    // Handle READ command
    if (msg.type == SFCTL_READ) {
        Parameter *p = paramManager.findParam(msg.value);
        if (!p) {
            proto.nack("UNKNOWN");
            return;
        }
        log_i("READ: %s = %s", msg.value.c_str(), p->toString().c_str());
        proto.ack(msg.value + "," + p->toString());
        return;
    }
});
```

### Example 5: Write Validation

```cpp
proto.registerSFCTLWrite([](const String &paramName, const String &paramValue) {
    Serial.printf("Parameter WRITE request: %s = %s\n", 
                 paramName.c_str(), paramValue.c_str());
    
    // Find the parameter
    Parameter *p = proto.find(paramName);
    if (!p) {
        Serial.printf("ERROR: Parameter '%s' not found\n", paramName.c_str());
        proto.nack("UNKNOWN");
        return;
    }
    
    // Check if parameter is writable
    if (!p->writable) {
        Serial.printf("ERROR: Parameter '%s' is read-only\n", paramName.c_str());
        proto.nack("READ_ONLY");
        return;
    }
    
    // Custom validation: reject negative values for numeric parameters
    if (p->type == PARAM_INT || p->type == PARAM_FLOAT) {
        float value = paramValue.toFloat();
        if (value < 0) {
            Serial.printf("ERROR: Negative value rejected for %s\n", paramName.c_str());
            proto.nack("INVALID_VALUE");
            return;
        }
    }
    
    // Validation passed - write the value
    Serial.printf("  Validation passed, writing value...\n");
    p->setValueFromString(paramValue);
    proto.save(*p);
    
    // Call onChange callback if registered
    if (p->onChange) {
        p->onChange(p);
    }
    
    // Send acknowledgment with new value
    proto.ack(p->name + "," + p->toString());
    Serial.printf("  Write complete: %s = %s\n", p->name.c_str(), p->toString().c_str());
});
```

// Register SFCTL handler using the NMEA route pattern
// This is the SAME pattern used for PFLAA, PFLAU, GPGGA, etc.
proto.registerNMEARoute("SFCTL", [](const String &talker, const String &type, 
                                     const std::vector<String> &fields) {
    Serial.println("SFCTL frame received via NMEA route!");
    Serial.printf("  Talker: %s\n", talker.c_str());    // "SF"
    Serial.printf("  Type: %s\n", type.c_str());        // "CTL"
    Serial.printf("  Field count: %d\n", fields.size());
    
    if (fields.empty()) {
        Serial.println("  Empty command");
        return;
    }
    
    String command = fields[0];
    Serial.printf("  Command: %s\n", command.c_str());
    
    // Handle custom PING command
    if (command == "PING") {
        Serial.println("  -> PING received, sending PONG");
        NMEAGenerator &gen = proto.getNMEAGenerator();
        proto.sendNMEA(gen.generateSFCTL_ACK("PING", "PONG"));
        return;
    }
    
    // Handle ECHO command with arguments
    if (command == "ECHO") {
        Serial.print("  -> ECHO: ");
        for (size_t i = 1; i < fields.size(); i++) {
            Serial.printf("%s ", fields[i].c_str());
        }
        Serial.println();
        
        // Echo back all arguments
        String echoMsg = "ECHO";
        for (size_t i = 1; i < fields.size(); i++) {
            echoMsg += "," + fields[i];
        }
        NMEAGenerator &gen = proto.getNMEAGenerator();
        proto.sendNMEA(gen.generateSFCTL_ACK(echoMsg));
        return;
    }
    
    // For unknown commands, send error
    proto.nack("UNKNOWN_VIA_ROUTE");
});

### Example 9: Access Control System

```cpp
// Define a simple access level system
enum AccessLevel { PUBLIC = 0, PROTECTED = 1, ADMIN = 2 };
AccessLevel currentLevel = PUBLIC;

// WRITE handler with access control
proto.registerSFCTLWrite([&currentLevel](const String &paramName, const String &paramValue) {
    // Define protected parameters
    bool isProtected = (paramName.startsWith("SYS_") || 
                       paramName == "DEVICE_ID" ||
                       paramName == "CALIBRATION");
    
    if (isProtected && currentLevel < ADMIN) {
        Serial.printf("ACCESS DENIED: %s requires ADMIN access\n", paramName.c_str());
        proto.nack("ACCESS_DENIED");
        return;
    }
    
    // Access granted - proceed with write
    Parameter *p = proto.find(paramName);
    if (p && p->writable) {
        p->setValueFromString(paramValue);
        proto.save(*p);
        
        if (p->onChange) {
            p->onChange(p);
        }
        
        proto.ack(p->name + "," + p->toString());
        Serial.printf("Access granted: %s written\n", paramName.c_str());
    } else {
        proto.nack("UNKNOWN");
    }
});

// Custom UNLOCK command to elevate privileges
proto.registerSFCTLCommand("UNLOCK", [&currentLevel](const std::vector<String> &fields) {
    if (fields.size() < 2) {
        proto.nack("MISSING_PASSWORD");
        return;
    }
    
    String password = fields[1];
    if (password == "admin123") {  // In production, use secure authentication!
        currentLevel = ADMIN;
        proto.ack("UNLOCK,GRANTED");
        Serial.println("Access level elevated to ADMIN");
    } else {
        proto.nack("INVALID_PASSWORD");
        Serial.println("Access denied: invalid password");
    }
});
```

## Best Practices

### 1. Error Handling

Always validate parameters before processing:
```cpp
if (!p) {
    proto.nack("UNKNOWN");
    return;
}
if (!p->writable) {
    proto.nack("READ_ONLY");
    return;
}
```

### 2. Use Type-Safe Methods

Prefer specific generator methods over generic build():
```cpp
// GOOD
String ack = gen.generateSFCTL_ACK("DEVICE_NAME", "SmartFlasher");

// AVOID
String ack = gen.build("SFCTL,ACK,DEVICE_NAME,SmartFlasher");
```

### 3. Acknowledge All Operations

Always send ACK or NACK responses:
```cpp
if (success) {
    proto.ack(p->name + "," + p->toString());
} else {
    proto.nack("INVALID_VALUE");
}
```

### 4. Validate Write Operations

Implement validation for parameter writes:
```cpp
// Range checking
if (value < min || value > max) {
    proto.nack("INVALID_VALUE");
    return;
}

// Type checking
if (!isNumeric(paramValue)) {
    proto.nack("INVALID_VALUE");
    return;
}
```

### 5. Log Important Events

Log parameter changes and errors:
```cpp
log_i("WRITE: %s = %s", paramName.c_str(), paramValue.c_str());
log_e("ERROR: Parameter '%s' not found", paramName.c_str());
```

### 6. Use Callbacks for Side Effects

Register onChange callbacks for parameters that affect system state:
```cpp
proto.addInt("POWER_LEVEL", 35, true);
proto.find("POWER_LEVEL")->onChange = [](Parameter *p) {
    // Update hardware when power level changes
    setPowerLevel(p->getInt());
};
```

### 7. Consistent Error Codes

Use standard error codes:
- `UNKNOWN` - Parameter or command not found
- `READ_ONLY` - Attempt to write read-only parameter
- `INVALID_VALUE` - Value validation failed
- `TIMEOUT` - Operation timeout
- `ACCESS_DENIED` - Insufficient permissions

### 8. Multiple Response Pattern

For commands returning multiple values, send multiple messages ending with ACK:
```cpp
proto.sendNMEA(gen.generateSFCTL_STATUS("UPTIME,12345"));
proto.sendNMEA(gen.generateSFCTL_STATUS("HEAP,32768"));
proto.sendNMEA(gen.generateSFCTL_ACK("STATUS", "COMPLETE"));
```

### 9. Unified NMEA Route Handling

Use registerNMEARoute for logging or routing all SFCTL traffic:
```cpp
// Log all SFCTL frames
proto.registerNMEARoute("SFCTL", [](const String &talker, const String &type,
                                     const std::vector<String> &fields) {
    log_i("SFCTL: %s", fields[0].c_str());
    // Let default handlers process the command
});
```

### 10. Don't Bridge SFCTL

SFCTL messages are for device control only and should NOT be forwarded to bridge devices. This is handled automatically by the protocol implementation.

## Troubleshooting

### Problem: NACK,UNKNOWN received

**Cause:** Parameter name doesn't exist

**Solution:** Verify parameter name with LIST command:
```
$SFCTL,LIST*60
```

### Problem: NACK,READ_ONLY received

**Cause:** Attempting to write to read-only parameter

**Solution:** Check parameter definition:
```cpp
proto.addString("DEVICE_NAME", "SmartFlasher", false);  // writable=false
                                                         // ↑ Change to true
```

### Problem: No response to SFCTL commands

**Cause:** Handler not registered or not calling `proto.process()`

**Solution:** Ensure loop calls process:
```cpp
void loop() {
    proto.process();  // Essential for processing incoming frames
}
```

### Problem: Checksum errors

**Cause:** Manual frame construction without proper checksum

**Solution:** Always use NMEAGenerator methods:
```cpp
// GOOD
String msg = gen.generateSFCTL_ACK("PARAM", "VALUE");

// BAD - missing checksum calculation
String msg = "$SFCTL,ACK,PARAM,VALUE*00";  // Wrong checksum!
```

### Problem: Parameters not persisting

**Cause:** Not calling save after write

**Solution:** Always save after modifying parameters:
```cpp
p->setValueFromString(paramValue);
proto.save(*p);  // Essential for persistence
```
